Physics-Based Combat Demo

I began developing this project at university, where I was tasked with building a working game system within a project. I decided to develop a navigation system that NPCs use to travel around a selected area. I built it by placing a set number of nodes in a grid across the floor, then connecting neighbouring nodes to form a navigation graph, skipping any connections that are blocked by walls. The enemy then uses breadth-first search (BFS), a pathfinding algorithm, to find the shortest route through this graph whenever it needs to move.

The enemy uses a behaviour tree, a hierarchy of nodes that decides what the enemy should do depending on what is happening around it. I also use a blackboard to store the main variables, such as whether the enemy can see the player and its current alert state. The enemy stays in its roaming state until it sees the player. It then chases the player by finding the node nearest to the player’s last known location, using that as the end point of its path, and updating the path every half second so it can follow the player as they move.

My next steps are to implement the smaller features needed to make this a fully playable demo, such as a goal and an attack from the enemy. These features are not in the project yet because the main aim of this tech demo was to showcase my skills in Unreal Engine and my ability to develop systems for video games. When I have spare time, I plan to come back and finish development to turn this into a full demo. .

Physics-Based Combat Demo

Physics is underused in hand-to-hand combat — most games fake the impact. This demo tests the alternative: a sword encounter where swing force is calculated from classical-mechanics formulas, so how you move the weapon is what determines how hard it hits.

I researched physics implementations across Super Mario Bros., Pong, Portal and Star Wars: The Force Unleashed, then built the movement and swing-force system over four weeks. A five-person playtest group confirmed the core concept worked.
